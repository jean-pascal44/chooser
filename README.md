# chooser

Petite **web app statique** (HTML, CSS, JavaScript) inspirée des applis type *finger chooser* : chacun pose un doigt sur l’écran, puis un participant est tiré au sort.

## Utilisation

Ouvrez simplement la page https://jean-pascal44.github.io/chooser/

## Contenu du dépôt

| Élément        | Rôle                                      |
| -------------- | ----------------------------------------- |
| `index.html`   | Structure de la page                      |
| `css/style.css` | Mise en forme et zone tactile             |
| `js/app.js`    | Pointeurs multiples, tirage, réinitialisation |

Le fichier `.no-jekyll` évite que GitHub Pages ne traite le site avec Jekyll.

## Genèse du projet

Le code et la documentation de ce dépôt a été **produite avec l’assistant IA de Cursor** (modèle conversationnel intégré à l’éditeur), **le 3 mai 2026**.
